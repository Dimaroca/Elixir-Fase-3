---Calculadora Básica en Elixir---

---Descripción---

Este programa es una calculadora básica desarrollada en Elixir.
Permite al usuario ingresar dos números y seleccionar una operación matemática para obtener el resultado.

El programa utiliza programación funcional mediante módulos y funciones, además de controles de flujo usando case.

---Funcionalidades---

El programa permite realizar las siguientes operaciones:

Suma
Resta
Multiplicación
División

---Funcionamiento---

El usuario ingresa dos números enteros.
El programa muestra un menú con las operaciones disponibles.
El usuario selecciona una opción.
Se ejecuta la operación correspondiente y se muestra el resultado en consola.
Estructura del Programa

El programa está organizado utilizando:

defmodule para crear el módulo principal.
Funciones (def) para cada operación matemática.
IO.gets para recibir datos del usuario.
IO.puts para mostrar resultados.
case para controlar el flujo del programa según la opción elegida.

---Requisitos---

Tener instalado Elixir.
Utilizar la terminal o consola para ejecutar el programa.
Ejecución

---Ejemplo de Uso---

Ingrese el primer número:
5

Ingrese el segundo número:
2

1. Suma
2. Resta
3. Multiplicación
4. División
